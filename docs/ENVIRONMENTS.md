# Environment matrix

The backend reads only environment variables (`backend/icp_api/settings.py`).

- **Local.** `.env` is loaded only when `APP_ENV` is unset or `local`. Real environment variables
  always win.
- **Staging and production.** Configuration is validated strictly at startup, and the process refuses
  to start if any rule is violated (see the last table).

Two deployed topologies are supported by the same code; the zero-cost one (docs/DEPLOYMENT.md) is
the default for staging. The paid-tier columns (D1 REST + R2 + Postgres/MLflow) remain valid.

| Setting | local (`npm run dev`) | test (pytest) | staging (zero-cost) | production (zero-cost) | paid-tier alternative |
|---|---|---|---|---|---|
| `APP_ENV` | `local` | `test` | `staging` | `production` | same |
| Backend host | `127.0.0.1:8000` | in-process TestClient | backend image on the operator machine behind a Quick Tunnel (container port 10000) | same (separate service) | any Linux host, `0.0.0.0:$PORT` |
| `METADATA_BACKEND` | `sqlite` (`var/metadata.db`) | `sqlite` (temp) + D1 REST + gateway simulators | `d1_gateway` (+ `GATEWAY_INTERNAL_URL`) | `d1_gateway` | `d1` (+ `D1_ACCOUNT_ID`, `D1_DATABASE_ID`, `D1_API_TOKEN`) |
| `OBJECT_STORE_BACKEND` | `local` (`var/objects`) | `local` (temp) + moto S3 + gateway simulator | `gateway` → KV `icp-objects-staging` | `gateway` → KV `icp-objects` | `s3` → R2 bucket |
| `MODEL_SOURCE` | `mlflow` | `mlflow` (+ bundle-mode test) | `bundle` | `bundle` | `mlflow` |
| `MLFLOW_TRACKING_URI` | `sqlite:///var/mlflow/mlflow.db` | temp SQLite | **unset** (operator machine only) | unset | Postgres |
| `MLFLOW_ARTIFACT_ROOT` | `var/mlflow/artifacts` | temp dir | unset | unset | `s3://<bucket>/mlflow` (+ `MLFLOW_S3_ENDPOINT_URL`, `AWS_*`) |
| Model updates | train/promote jobs | same | `icp-api export-model` from the operator machine | same | train/promote jobs on the server |
| Schema migrations | applied on startup | applied by fixture | `wrangler d1 migrations apply --remote` | same | same |
| Dataset seed | from `data/raw` on startup | from `data/raw` | `icp-api seed` from the operator machine (gateway stores) or admin CSV import | same | admin CSV import |
| `ADMIN_API_TOKENS` | generated by `npm run setup` | fixed test token | container env file under `var/secrets/` (≥ 32 chars each) | host env | platform secret |
| `GATEWAY_SHARED_SECRET` / `REQUIRE_GATEWAY_SECRET` | generated / `false` | test value / per test | `wrangler secret` + container env / `true` | same | same |
| `CORS_ALLOWED_ORIGINS` | Vite + wrangler dev origins | same | the gateway origin only (or empty: same-origin) | same |
| `LOG_FORMAT` | `console` | `console` | `json` | `json` |
| `EXPOSE_API_DOCS` | `true` | `true` | `true` | `false` |
| `METRICS_TOKEN` | empty | empty | **set** (≥ 32 chars, required) | **set** (≥ 32 chars, required) |
| `SEED_DIR` / `SEED_FROM_REPOSITORY` | `data/seed` / `true` (benchmarks + FX seeds, ICP/WTI from `data/raw`) | same | `false` (data comes from ingestion jobs) | `false` |
| `EIA_API_KEY` | empty (EIA mirror used) | empty | recommended (free key) | recommended |
| `SOURCE_CACHE_DIR` / `SOURCE_STATE_DIR` | `var/cache/sources` / `var/sources` | temp | persistent volume or leave default (re-downloadable) | same |
| `PUBLIC_REGISTRATION_ENABLED` | `true` | `true` | per decision (`false` = invite-only) | per decision |
| `TESSERACT_CMD` | optional (Windows path) | unset | binary on PATH in the container image | same |
| Gateway Worker | `wrangler dev` (`.dev.vars`) | vitest (mocked bindings) | `wrangler deploy --env staging` | `--env production` | same |
| Gateway `BACKEND_URL` | `http://127.0.0.1:8000` | mocked | Quick Tunnel URL, passed with `--var` at deploy time | production backend URL | backend URL |
| Gateway bindings `DB` / `OBJECTS` | none (backend uses SQLite/local) | fake bindings | `icp-metadata-staging` / `icp-objects-staging` | production ids (placeholders) | not needed |
| Edge rate limits | simulated by wrangler dev | mocked | namespaces 41011/41012 | 41021/41022 | same |

Columns for `CORS_ALLOWED_ORIGINS`, `LOG_FORMAT`, `EXPOSE_API_DOCS`, `METRICS_TOKEN`, `SEED_DIR`,
`EIA_API_KEY`, `SOURCE_*`, `PUBLIC_REGISTRATION_ENABLED` and `TESSERACT_CMD` apply unchanged to both
deployed topologies.

## Deployed-configuration validation (enforced at startup)

| Rule | Reason |
|---|---|
| `METADATA_BACKEND` is `d1_gateway` (with `GATEWAY_INTERNAL_URL`) or `d1` (with `D1_*`) | deployment filesystems are not persistent |
| `OBJECT_STORE_BACKEND` is `gateway` (with `GATEWAY_INTERNAL_URL`) or `s3` (endpoint, bucket, keys) | same |
| `MODEL_SOURCE=bundle`, or `MODEL_SOURCE=mlflow` with a non-SQLite `MLFLOW_TRACKING_URI` and an `s3://` `MLFLOW_ARTIFACT_ROOT` | the served model must survive redeploys: either an exported bundle in the object store or a persistent registry |
| `GATEWAY_SHARED_SECRET` ≥ 32 chars whenever the gateway data plane is used (any env) | the data plane is authenticated by this secret alone |
| `REQUIRE_GATEWAY_SECRET=true` with a secret of ≥ 32 chars | the backend must not be directly usable |
| each admin token ≥ 32 chars | brute-force resistance |
| `CORS_ALLOWED_ORIGINS` has no `*` | no wildcard CORS |

## Gateway Worker variables

| Name | Kind | Notes |
|---|---|---|
| `BACKEND_URL` | var (per env in `wrangler.jsonc`) | backend URL; placeholder in the file - staging passes the tunnel URL with `wrangler deploy --var` |
| `GATEWAY_SHARED_SECRET` | **secret** | `wrangler secret put GATEWAY_SHARED_SECRET --env <env>`; local: `apps/gateway/.dev.vars`; also authenticates `/api/internal/*` |
| `MAX_BODY_BYTES`, `UPSTREAM_TIMEOUT_MS`, `ENVIRONMENT` | var | defaults 2000000 / 30000 (90000 for deployed envs: slow or waking backends) |
| `API_RATE_LIMITER`, `FORECAST_RATE_LIMITER` | rate-limit bindings | 300/min and 20/min per client key (internal routes are exempt) |
| `DB` | D1 binding | application metadata, served to the backend via `POST /api/internal/d1/query` |
| `OBJECTS` | KV binding | objects, served via `GET/HEAD/PUT /api/internal/objects/<key>` |
